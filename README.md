This is a project about representing an image as a 2D list/array of values ranging from 0 to 255,
and performing different operations on it.

Following are the operations & functions available to do in the code:

1)GenImg(): Generates an Image of size nxn

2)PadImg(): Adds a layer of padding to given Image

3)InvImg(): Inverts value of each pixel, by subtracting its value from 255

4)BriImg(): Brightens/increases value of each pixel by given amount upto 255

5)ThrImg(): Changes pixels whose value is above/equal to given threshold to 255 and rest to 0

6)FliImg(): Flips each row's pixel's values horizontally

7)RotImg(): Rotates Image by 90 degrees clockwise

8)BluImg(): Blurs pixels of Image by taking mean of 3x3 pixels around it.
